# Security Policy

## Supported versions

Moderato.Effects is currently in preview. Security fixes target the latest preview release of each affected package. Older preview releases do not receive backported fixes. Packages are versioned independently.

Please report suspected vulnerabilities even if you found them in an older release.

## Reporting a vulnerability

Use GitHub's [private vulnerability reporting](https://github.com/SingUp009/Moderato.Effects/security/advisories/new) to report a suspected vulnerability in the packages, source generators, or analyzers maintained in this repository. Do not disclose vulnerability details in public issues or pull requests.

Include the following information when available:

- Affected packages and versions.
- .NET SDK and runtime versions, operating system, and relevant application configuration.
- A minimal reproduction or clear steps to reproduce the issue.
- The potential impact and any known workaround.

Remove credentials, personal data, and other secrets from reproductions and logs.

Maintainers will use the private report to discuss the findings, any fix, and public disclosure with you. Response and resolution times depend on maintainer availability and the issue; no fixed timeline is guaranteed.

For ordinary bugs and usage questions, use [GitHub Issues](https://github.com/SingUp009/Moderato.Effects/issues).
