# Moderato.Effects.Hosting

Generic Host integration for [Moderato.Effects](https://github.com/SingUp009/Moderato.Effects).

Run typed effects as background services with execution-scoped dependencies and Host-owned diagnostics through standard `ILogger` providers.

See the [Hosting guide](https://github.com/SingUp009/Moderato.Effects/wiki/Hosting) for registration, error handling, shutdown and ownership contracts.

Requires .NET 11 and C# 15. Both .NET 11 and this library are in preview.
